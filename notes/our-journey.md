# مشروع شادي لتعليم الـ AI بداية من الـ GitHub

## اسم المشروع الرسمي
Shady - مشروع شادي لتعليم AI

## الهدف
احتراف الـ AI من الصفر

## اتفاقنا الثابت
1. كل خطوة اسمها بالانجليزي وترجمتها بالعربي
2. كل خطوة عملناها ليه
3. شرح بسيط ومناسب لمبتدئ من الصفر على الايفون

## اللي عملناه لحد دلوقتي
1. Repository - المستودع / المحل - عملنا Shady
2. README.md - اليافطة - كتبنا مشروع شادي - تعليم AI
3. Commit - حفظ وتاكيد - بندوسه عشان نثبت اي تغيير
4. File - ملف / ورقة - عملنا my-plan.txt
5. Folder - مجلد / درج - عملنا notes عن طريق /
6. Navigation - التنقل - بندخل الدرج ونطلع منه
